# 当前研究方向

最新授权是最多三轮真实交互纠错：每轮由当前完整配对学生产生状态，专家接管；两组成功纠偏进入持续共享池，冻结共同快照后训练现有前端与后端，再有限自主评估并决定下一轮配对。旧单轮12h/12机会与附件最初的“只更新后端”均已覆盖。普通owner在验收与资源条件满足后自动推进，不追加无新交互的长时间离线循环。

优先QG01、随后G11，从已完成 `tight_dagger_20261111_01` 各自selected完整前后端pair出发。沿用U-Net、持续历史和Transformer，不从零训练、不交换组定义。每轮每组默认32训练分布机会，4个整episode预登记为纠偏开发集；总最多192机会，不以成功数补采。自主评估先固定4例，满足登记的成功/子目标/lift条件才扩至10；零自主成功本身不取消有界下一轮。

本轮属于成功筛选的专家接管式 DAgger。学生前缀是实际因果历史，监督为零；只有成功 episode 中专家真正执行的有效后缀用于监督。前端分别学习命令 `u_expert` 或实际到达配置 `q_reached`，后端统一学习最终专家命令。H24 标签不能跨控制切换/无效段/reset，学生 q_after 不能充当专家反事实 q_reached。

先更新前端，再冻结所选新前端并为完整train/validation/correction_dev刷新名义预测缓存，最后更新后端。原训练统计不重拟合，原幅度边界不放大；Core/历史/本轮纠偏按.5/.2/.3抽样，实际曝光与重复覆盖公开；旧val/纠偏dev/首24有效tick相对真实update0按.5/.25/.25选模，update0可保留，上轮完整pair可回退，不能任意拼装best。test22不使用。记录超出后端范围的标签比例及输出饱和，不能用延长训练掩盖表达范围不足。

总量最多三轮、新root实际起点18小时内，包含等待与最后10分钟发布；恢复不重置deadline。前端最多10/最低6有效anchor遍，后端最多12/最低6有效tick遍，阶段时间与数据条件优先。实际尝试、专家查询/执行、有效标签、真实训练曝光、等待与自主分母都要披露；接管成功不能解释成学生学会。不能仅凭 G11/QG01 两组证明几何或触觉的独立因果收益。
