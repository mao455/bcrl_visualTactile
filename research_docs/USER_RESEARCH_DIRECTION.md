# 当前研究方向

下一阶段优先完成一轮真实交互纠错：原实验正常收尾后，自动采集学生造成状态上的专家接管数据，聚合训练现有前端和后端，再有限自主评估。最新用户更正要求前后端都学习；附件最初的“只更新后端”已经覆盖。无需等用户再次发送开始，也不先追加一轮无新数据的长时间离线训练。

首轮只比较 G11 与 QG01。G11 从已有 G10 命令前端和当前选定 Transformer 后端出发；QG01 从当前选定 QG00 配置/几何前端和对应后端出发。沿用 U-Net、持续历史和后端 Transformer，不从零训练、不交换组定义。两组各12次相同规则的训练分布机会，不以成功数补采；聚合后各10个既有固定开发初态，全程学生自主执行。

本轮属于成功筛选的专家接管式 DAgger。学生前缀是实际因果历史，监督为零；只有成功 episode 中专家真正执行的有效后缀用于监督。前端分别学习命令 `u_expert` 或实际到达配置 `q_reached`，后端统一学习最终专家命令。H24 标签不能跨控制切换/无效段/reset，学生 q_after 不能充当专家反事实 q_reached。

先更新前端，再冻结所选新前端并为完整 train/validation 刷新名义预测缓存，最后更新后端。原训练统计不重拟合，原幅度边界不放大；固定 validation 选模，test22 不使用。记录超出后端范围的标签比例及输出饱和，不能用延长训练掩盖表达范围不足。

总量是一轮、新起点12小时内的有限队列。实际尝试、专家查询/执行、有效标签、真实训练曝光、等待与自主分母都要披露；接管成功不能解释成学生学会。不能仅凭 G11/QG01 两组证明几何或触觉的独立因果收益。

旧 `tight_transformer_20261110_02` 保持原计划运行；新代码在隔离工作树准备。普通后继程序依据实际退出和有效 checkpoint 自动推进，注册与运行各有机器凭据。清理以依赖为准，旧权重和报告不再默认永久保留；原400、仍用 Core、专家/资产及活动/排队依赖保护。
