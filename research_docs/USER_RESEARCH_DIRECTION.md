# 用户研究思路与方向性要求

这份文档保存用户为什么做这个项目，以及哪些方向已经确定。它不是网络设计说明，也不把助手选的结构升级成用户决定。后续 agent 应先读本文件，再读工程合约。若用户改变方向，在末尾追加日期、原要求、新要求和理由；不要静默覆盖。

## 用户明确要求（2026-10-27 汇总）

1. **几何运动与接触执行分工。** Nominal Diffusion Policy 的长期目标是学习任务的几何运动意图；接触预加载、稳定夹持、压力和滑移等执行问题由独立 Correction 研究。普通示范位置命令可能通过越过接触位置隐式施压，不能把普通 BC 或专家动作改名后就称为纯几何动作。
2. **Nominal 不直接读触觉。** 不读 tactile、Correction 内部状态、触觉修正后的混合命令或执行目标。允许视觉、proprioception、合法任务命令、自身过去预测等非触觉信息。实际关节运动可能间接受接触影响，这是机器人状态本身；不等于额外开通触觉通道。
3. **Correction 是独立多模态策略，不是触觉编码器。** 触觉编码器提供特征；策略还需视觉、运动、真实历史执行命令/目标以及 Nominal 当前和未来意图。Correction 不等同于简单动作相减，也不强制只能输出很小的残差。未训练网络保持 Shadow，不能驱动机器人。
4. **完整因果历史。** 从 episode 开始的历史应有持续影响决策的通路，可以同时保留近期详细窗口。不能只把窗口从4改到12或每次重规划重新初始化。更新观测记忆与重新规划要分开；每个并行环境独立，真正 reset 才清空，普通子目标变化不清空。固定维度记忆不可能无损保存整段原始轨迹，原始轨迹必须另存。
5. **训练与推理历史一致。** 分块是读取方式，截断梯度是优化选择，清空记忆是 episode 生命周期；三者不同。训练不能默认在随机短窗口用零记忆，而推理却假定理解了完整前缀。用固定参数比较整段、分块和逐步处理。
6. **完整动作—执行—结果记录。** 每步能追溯动作前观测、实际计算过的模型结果、最终提交命令、延迟/平滑后的控制目标、实际运动、接触、图像及事件。真实缺失必须标明，不能用 reset 后图像替代终止帧。
7. **专家过去动作可以利用。** 已经发过的专家命令可以是明确标注的历史/teacher-forcing；当前和未来专家动作只能是监督。某模型过去预测而未执行的未来计划只能由该模型真实推理得到，不能用随后发生的专家动作冒充。旁路预测需记录模型、生成时刻、覆盖时间和是否执行；专家执行后果不能归因于未执行预测。
8. **任务间可能共享结构。** 不同任务可能共享动作和几何关系。task ID 暂时保留为类别标识，没有物理大小意义；它不是最终目标表达方案。本轮不新增任务规划器或目标估计网络。
9. **先建设可信接口，不正式训练。** 当前不进行正式 BC、Correction、RL、超参数搜索或成功率优化。允许少量专家观察、真实数据回放、前向/梯度/保存恢复检查；这些不证明网络学到了任务能力。
10. **参考成熟公开实现。** 先理解原代码和公开方法，再做兼容适配；检查来源、许可、依赖，避免大规模未经验证重写。网络可以替换，选择应有证据。
11. **保留原资产、控制和物理。** 不擅自改碰撞、关节限位、摩擦、增益、动力学、任务判据、原随机化/延迟与坐标转换。新增接口局部、可选，原路径应可运行。频率修改不能偷偷改变动作幅度。
12. **可接手、可审计。** 每次修改更新工程文档、真实测试和 Git 历史。保护本机后台任务，不公开数据、checkpoint、凭据或其他人的文件。本项目与另一项小物体抓取、cuRobo、批量 PKL 生产项目不同，不能混入它的代码、数据或成果。

## Codex 暂定工程决策（不是用户冻结的研究结论）

- 当前选择逐步携带 GRU 状态，保留近期原始窗口。Nominal 每60Hz控制观察更新；Correction 的五指力/FK按120Hz样本更新，其余分支60Hz。没有新增有损下采样。
- 保留 HDF5 精确数值和随机切片，增加逐步读取、逐步追加/flush和单 episode PKL 导出；不迁移整条数据管线。
- 默认 Nominal 仍只使用自己的预测历史。数据接口另行暴露专家过去命令，未来若选择 teacher-forcing，必须明确增加源标记、兼容版本和训练/部署对照，不能暗塞进 `previous_nominal_action`。
- 任务类别继续用 embedding。没有新增 planner；预加载 nominalization 与 Correction 训练方案继续留空，不制造假损失。

## 助手建议，尚未实施或决定

- 后续比较记忆容量、可查询的历史摘要与在线数据分布；长时依赖可能在 GRU 中衰减。
- 完整因果回放可产生新版本模型的真实预测，但应记录新模型与回放时间；不可继承旧模型版本或把这些预测当作已执行。
- 在有充分数据和明确监督后，先比较 Nominal-only，再做触觉/历史/视角消融；本轮不执行这些训练。
